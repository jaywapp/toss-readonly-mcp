# 성능·회귀·오류 방어 분석

orchestrator: Codex

사용자가 질문 없이 기존 동작 기준으로 개선·테스트·오류 방어를 요청했다. 공개 API 계약과 검색 순위를 유지하고 인증·시세를 실제 호출하지 않는다.

확인한 문제: SQLite 연결 context manager는 트랜잭션만 종료하고 연결을 닫지 않는다. `UPPER(symbol)` 조회는 기존 기본키 인덱스를 사용하지 못한다. 공백 검색도 전체 시장 수집을 시작한다. Retry-After의 NaN/무한대/음수와 만료시간 무한대가 잘못된 대기 또는 예외를 만들 수 있다.

기존 테스트를 기준으로 연결 정상/실패 종료, 검색 순위/빈값/동시 조회, 네트워크·권한 오류를 검증한다. 외부 장애를 성공 데이터로 위장하지 않는다. 전체 기존 스위트와 추가 회귀를 실행하며 실제 API smoke는 제외한다.
