# toss-mcp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 토스증권 Open API 를 읽기 전용 MCP 도구 13개로 노출해, LLM 이 국내·미국 주식의 시세·종목정보·시장정보·랭킹을 조회할 수 있게 한다.

**Architecture:** 계층 분리. `config` → `auth`/`ratelimit` → `client` → `tools`. `client` 는 도구를 모르고 `tools` 는 HTTP 를 모른다. `symbols` 는 토스 API 와 무관하게 FinanceDataReader + SQLite 로 종목명↔심볼을 해결하며 단독 테스트 가능하다.

**Tech Stack:** Python 3.12, uv, fastmcp, httpx, pydantic v2, pydantic-settings, finance-datareader, pytest, pytest-asyncio, respx

**설계 문서:** `docs/superpowers/specs/2026-08-04-toss-mcp-design.md`

## Global Constraints

- Python 3.11 이상 (개발 환경은 3.12.10)
- 전 도구 읽기 전용. 계좌·주문 엔드포인트는 구현하지 않는다.
- 시크릿(`TOSS_CLIENT_ID`/`TOSS_CLIENT_SECRET`)을 로그·에러 메시지·도구 응답에 절대 출력하지 않는다.
- 금액·수량은 `decimal` 문자열을 그대로 유지한다. `float` 변환 금지 (정밀도 손실).
  등락률 계산에만 `decimal.Decimal` 을 사용한다.
- 도구 응답은 LLM 컨텍스트에 들어간다. 스펙의 모든 필드를 흘리지 말고 필요한 필드만 반환한다.
- 사용자 대면 문자열(도구 description, 에러 메시지)은 한국어. 코드·식별자·커밋 메시지는 영어.
- 기본 테스트 스위트는 네트워크를 타지 않는다. 실 API 호출은 `@pytest.mark.smoke` 로 분리.
- Base URL 기본값 `https://openapi.tossinvest.com`, 스펙 v1.2.9 기준.

## Rate limit 그룹 (전 태스크 공통)

| 그룹 | 한도 |
|------|------|
| `AUTH` | 5/s |
| `MARKET_DATA` | 10/s |
| `MARKET_DATA_CHART` | 5/s |
| `STOCK` | 5/s |
| `MARKET_INFO` | 3/s |

## Task 5: HTTP 클라이언트

**Files:**
- Create: `src/toss_mcp/client.py`
- Test: `tests/test_client.py`

**Interfaces:**
- Consumes: `Settings`, `TokenProvider`, `RateLimiter`, `TossApiError`, `TossConnectionError`
- Produces: `class TossClient` — `async get(path: str, group: str, params: dict|None = None) -> Any`
  (성공 시 envelope 의 `result` 만 반환), `async aclose() -> None`.
  모듈 함수 `get_client() -> TossClient` (프로세스 싱글턴, lazy).
  재시도: 401 은 `invalidate()` 후 **1회**, 429 는 `Retry-After` 우선·없으면 지수 백오프
  (1→2→4초) + jitter 로 **최대 3회**.

- [ ] **Step 1:** 실패 테스트 (respx) — 성공 시 `result` 언랩, `Authorization: Bearer` 헤더 부착,
  `None` 파라미터 제거, 401→재발급 후 재시도 성공, 401 두 번이면 `TossApiError`,
  429→`Retry-After` 존중 후 성공, 429 4연속이면 `TossApiError(code="rate-limit-exceeded")`,
  `httpx.ConnectError` → `TossConnectionError`
- [ ] **Step 2:** 테스트 실패 확인
- [ ] **Step 3:** `client.py` 구현 (`sleep_fn` 주입으로 테스트에서 실제 대기 없음)
- [ ] **Step 4:** 테스트 통과 확인
- [ ] **Step 5:** 커밋 `feat: add Toss API client with retry and token refresh`

## Task 6: 종목 마스터

**Files:**
- Create: `src/toss_mcp/symbols.py`
- Test: `tests/test_symbols.py`

**Interfaces:**
- Consumes: `Settings`
- Produces: `@dataclass SymbolRecord(symbol, name, english_name, market)`
  `class SymbolStore(settings, fetcher: Callable[[str], list[SymbolRecord]] | None = None)`
  — `async search(query: str, market: str|None = None, limit: int = 10) -> list[SymbolRecord]`,
  `async refresh() -> dict` (`{markets, count, updated_at}`),
  `async name_for(symbol: str) -> str|None`,
  `async names_for(symbols: list[str]) -> dict[str, str]`.
  모듈 함수 `get_store() -> SymbolStore`.
  SQLite: `{cache_dir}/symbols.db`, 테이블 `symbols(symbol PK, name, english_name, market, updated_at)`,
  `name` 인덱스. FDR 호출은 `asyncio.to_thread` 로 감싼다.
  **FDR 컬럼 매핑**: 심볼은 `Symbol`→`Code` 순, 이름은 `Name`→`Description`→`Symbol` 순으로 존재하는 첫 컬럼 사용.

- [ ] **Step 1:** 실패 테스트 (fetcher 주입, 임시 `cache_dir`) — 검색 랭킹 4단계 순서
  (심볼 정확 → 이름 정확 → 접두 → 부분), 동일 단계에서 보통주 우선·이름 길이 오름차순
  (`삼성전자` < `삼성전자우`), `market` 필터, `limit` 적용, 대소문자 무시(`aapl`→`AAPL`),
  TTL 만료 시 자동 재수집, TTL 이내면 재수집 안 함, **동시 검색 시 fetcher 1회만 호출**,
  `names_for` 가 마스터에 없는 심볼을 조용히 생략
- [ ] **Step 2:** 테스트 실패 확인
